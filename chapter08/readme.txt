To run the regular expressions compiler, use re.Main in MyRVTool folder

To run the FiTS system, use fits.Main

Note: MyRVTool/egcl also has its own Main -- that's the EGCL compiler from
Chapter 6, kept here only because re.Main depends on it internally. There's
no script/properties.egcl in this chapter for it to compile, so running
egcl.Main directly here isn't meaningful; run re.Main instead.
