To run the Automata compiler, use automata.Main in MyRVTool folder

To run the FiTS system, use fits.Main

Note: MyRVTool/egcl also has its own Main -- that's the EGCL compiler from
Chapter 6, kept here only because automata.Main depends on it internally.
There's no script/properties.egcl in this chapter for it to compile, so
running egcl.Main directly here isn't meaningful; run automata.Main instead.
